## Introduction

Small LANs may work with a single network, but organizations need to
separate users, services and devices for performance, management and
security reasons.

VLANs create independent logical networks over the same physical
infrastructure.

## 1. Why segmentation is needed

A VLAN defines an independent broadcast domain.

Segmentation allows:

-   reducing unnecessary traffic;
-   organizing users;
-   applying different policies;
-   improving administration.

A VLAN does not replace IP addressing: each VLAN is normally associated
with an IP subnet.

## 2. VLAN design

Before configuring, answer:

-   which devices belong to each group;
-   which communication is required;
-   which subnet each VLAN uses;
-   where the default gateway is located.

Examples:

-   user VLAN;
-   server VLAN;
-   guest VLAN;
-   voice VLAN.

## 3. Access ports

An access port normally connects an end device.

Traffic belongs to a single VLAN.

Examples: - computers; - printers; - cameras; - IP phones.

## 4. Voice VLAN

An IP phone can share a physical connection with a computer.

The network can transport:

-   data traffic;
-   separated voice traffic using tagging.

## 5. 802.1Q trunks

When a link must carry multiple VLANs, a trunk is used.

802.1Q adds information that identifies the VLAN associated with a
frame.

Common trunk connections:

-   switch to switch;
-   switch to router;
-   switch to multilayer switch.

## 6. Native VLAN and allowed VLANs

Both trunk endpoints must have compatible configuration.

Important concepts:

-   native VLAN;
-   allowed VLANs;
-   active VLANs.

## 7. VLAN and STP

VLANs interact with Layer 2 loop prevention mechanisms.

STP and VLAN configuration must work together.

## 8. EtherChannel with VLANs

EtherChannel links can transport multiple VLANs when configured as
trunks.

## 9. Inter-VLAN routing

VLANs separate broadcast domains, but devices in different VLANs need a
router or multilayer switch to communicate.

Main methods:

### Router-on-a-stick

A router uses subinterfaces over a trunk link.

### Multilayer switch

A Layer 3 switch uses SVIs as gateways.

## 10. VLAN troubleshooting

Professional troubleshooting follows:

symptom → facts → hypothesis → test → evidence → correction →
verification.

Common problems:

-   missing VLAN;
-   wrong access assignment;
-   incorrect trunk;
-   VLAN not allowed;
-   native VLAN mismatch;
-   wrong gateway.

## Key idea

A VLAN is not only a switch configuration. It is a design decision
connecting organization, addressing, connectivity and administration.
